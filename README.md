# Mon site

Un site web simple en HTML et CSS.

## Voir le site

Ouvre `index.html` dans un navigateur.

Pour le mettre en ligne gratuitement avec GitHub Pages :
Settings → Pages → Source : « Deploy from a branch » → choisis la branche et le dossier `/ (root)`.

## Fichiers

- `index.html` : le contenu de la page
- `style.css` : l'apparence (couleurs, mise en page, mode sombre automatique)
